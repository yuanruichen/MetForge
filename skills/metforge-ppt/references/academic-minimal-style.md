# Academic Minimal: observed design profile

Based on Academic_Minimal_Final.potx and a researcher-provided QBO–MJO talk.
The original template, example research deck, results and assets are not distributed with this
skill and do not supply evidence for another project. New user choices override
these defaults.

| Element | Observed convention / useful default |
| --- | --- |
| Canvas | 12,192,000 × 6,858,000 EMU; 13⅓ × 7½ inches; 16:9 |
| Background | White; dark text; sparse grey rules, no ornamental cards |
| Alignment | Left x≈0.65 in; right x≈12.68 in |
| Cover | Rockwell 44 pt; scientific title and short research question |
| Content title | Segoe UI Semibold 32 pt; y≈0.6 in |
| Explanations | Segoe UI 20 pt; about 18 pt for compact annotations |
| Subtitle / author | About 21 / 17 pt |
| Captions | About 14 pt grey; units, period, method and source |
| Line spacing | User requirement: at least 1.15× for all editable slide text, including titles, captions and tables; paragraph spacing is separate |
| Comparisons | Matching geographic extent, scales and axis limits |
| Color | Restrained accent; consistent with the scientific figure legends |

Explicit shape fonts matter: the theme's Aptos is not the Rockwell/Segoe type
actually used in the slides. Preserve requested PPTX fonts and disclose preview
substitution if unavailable, or use an agreed portable font. Never claim exact
font matching after silent substitution.

Six template layouts: cover (1), section (2), dominant figure (3), comparison
(4), evidence/interpretation (5), and concept/equation (6). Select layouts as
needed; this is not a mandatory six-slide sequence.

The example uses conclusion-led titles, large plots, one or two short findings,
small method footers, full-width evidence or figure-left/text-right pages, and
an established/unresolved ending. Do not copy typos, crowded titles or blank
bullets. Reserve roughly y=1.45–6.6 for evidence and y=6.85–7.3 for footers.
Keep titles to at most two lines; shorten before reducing their font. Split or
select named panels when a figure is unreadable at presentation size.

English is the reference's language, not a universal rule. Match the current
audience/request; notes may use the researcher's working language.
