# Diagnostic evidence report

Use a compact table rather than a chronology of commands.

| Field | Content |
|---|---|
| Question | Property or failure under investigation |
| Hypothesis | Current explanation |
| Falsifier | Observation that would reject it |
| Reference | Analytic, benchmark, control, or converged solution |
| Controlled factor | The single changed factor |
| Configuration audit | Other differences found or ruled out |
| Metrics | Exact definitions, weighting, normalization, and window |
| Evidence | Quantitative results and linked figures/files |
| Classification | Expected / suspicious / inconsistent / configuration-dependent / inconclusive |
| Alternatives | Remaining plausible explanations |
| Next test | Smallest discriminating experiment |

## Claim discipline

Separate:

- **Observation:** directly measured from outputs.
- **Inference:** explanation supported by the observation and test design.
- **Assumption:** condition not yet verified.
- **Decision:** why the next test is preferred.

Do not promote correlation, visual resemblance, or one sensitivity result to a mechanism without a term-level or controlled test.
