# Writing

Use this skill when the task is mainly about turning diagnostics, figures, logs,
or notes into clear technical writing.

## Use For

- Scientific or technical summaries.
- Report sections.
- Figure captions.
- Documentation pages.
- Literature-connected discussion.
- Open questions and next-step notes.

## Instructions

1. Define scope before writing.
   - Identify the relevant files, figures, logs, and user-provided context.
   - Exclude unrelated products.
2. Organize by content, not by command history.
3. Prefer short sections and concise bullets.
4. Anchor scientific reports around figures when figures exist.
5. Captions should include variable, units, period/sample, and method.
6. Tie interpretation directly to visible evidence or cited sources.
7. Add references only when they help the argument.
8. End research notes with concrete open questions or next checks when useful.

## Style

- Write plainly and precisely.
- Make one claim per bullet or sentence.
- Avoid terminal transcripts and implementation chatter.
- Use repo-relative links for local files.
- Keep citations stable and include DOI or durable links when practical.

## Verification

Before finalizing, check that:
- the scope matches the request
- important figures or outputs are linked correctly
- captions are specific
- claims are supported by evidence or clearly marked as interpretation
- the result is concise enough to be useful
